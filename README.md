# BodyMetrics Pro — Calculadora de Grasa Corporal y Composición

Aplicación web interactiva para calcular el porcentaje de grasa corporal, composición corporal (masa grasa vs. masa magra), IMC, FFMI y gasto energético diario (BMR / TDEE).

## Métodos incluidos
- **Marina de EE. UU. (Hodgdon & Beckett):** Cinta métrica (cuello, cintura, cadera y altura).
- **Pliegues Cutáneos (Jackson-Pollock 3 y 7 sitios + Siri):** Medición con plicómetro en milímetros.
- **Estimación por IMC (Deurenberg):** Basada en peso, altura, edad y sexo biológico.

## Despliegue rápido
Este proyecto es 100% estático (`index.html`, `styles.css`, `app.js`) y puede desplegarse directamente en:
- **Netlify Drop:** Arrastrando la carpeta del proyecto a [app.netlify.com/drop](https://app.netlify.com/drop).
- **GitHub Pages:** Subiendo este repositorio a GitHub y activando *Settings → Pages* desde la rama `main`.
- **Vercel / Cloudflare Pages:** Importando el repositorio de GitHub sin necesidad de comando de compilación.
